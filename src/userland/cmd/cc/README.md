# The C compiler: cpp, cc0, cc1, cc2, cc3 and the cc driver

Mark Williams C 4.2.12 (the machine-independent passes, BSD-3-Clause, Robert
Swartz) with a Zilog Z8001 back end (Kevin Dedon, MIT), taken from
https://github.com/kdedon/commodore-900-toolchain (`src/cc` at commit bccf705,
Sept 2026) with the changes listed in `CC_BUGS.md` at the root of this tree.
It replaces the 1985 binaries that shipped as `/lib/cpp cc0 cc1 cc2 cc3` and
`/bin/ccx` (those survive in `_disasm/`, which decompiles them).

Layout, as upstream:

| dir | what |
|---|---|
| `n0` | cc0, the front end: lexer, preprocessor, parser, symbol and type tables |
| `n0/split` | the halves that make cpp and cc0 two programs (see below) |
| `n1` | cc1, the code generator; `n1/z8001` the Z8001 machine layer; `n1/tables` the selection grammar (`.t`) and the C GENERATED from it |
| `n2` | cc2, the peephole optimizer and object writer; `n2/z8001` its machine layer |
| `n3` | cc3, the intermediate-code printer (`cc -S`) |
| `common` | intermediate-code I/O, diagnostics, variant words; `common/z8001` name tables and the passes' own heap |
| `h` | headers; `h/z8001` the machine's |
| `coh` | `cc.c`, the driver; `tabgen.c`, the table generator (a HOST program, not built here) |
| `generated` | opcode tables the machine layers share |

One source, two front-end programs: `n0/cc0.c`, `get.c` and `cpp.c` are
compiled twice, with `-DNOCPP` into `/lib/cc0` (the parser, reading cpp's
output) and with `-DCPPONLY` into `/lib/cpp` (the preprocessor alone).  The
driver runs `cpp | cc0 | cc1 | cc2`, then `/bin/ld`.

cc0, cc1 and cc2 link `-L` with `common/z8001/bigheap.c`: a K&R allocator over
four 60 K arenas (`arena0..3.c`, one module each so `ld -L` gives each a data
segment) in place of malloc, because a kernel-sized file needs more heap than
one 64 K data segment leaves.  Debug tables and the assembly listing are not
built in (`n0/split/nodbg0.c`, `n2/z8001/nodbg2.c` stand in for them).

`n1/tables/macros.c` and `patern.c` are generated by `tabgen` from the `.t`
files and are committed; regenerate them with a host C compiler when a `.t`
changes:

    cc -o tabgen coh/tabgen.c && (cd n1/tables && ../../tabgen -s prefac.f *.t)
