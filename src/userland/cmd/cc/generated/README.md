# Generated Z8000 opcode tables — the two files the compiler compiles

**Provenance:** produced by `genz8001tab` by driving a **verified decoder**
exhaustively over the entire 16-bit opcode space (segmented mode). Every byte
here comes from the same decoder the emulator's reference model executes — no
transcription, no reverse-engineering, and **not** from the faulty
`Z8000_instruction_encodings.md`.

**The generator is not in this repository** and cannot be run from it: it reads
a decoder that is not public. These files are committed artifacts, checked
against each other by the gates below, and the compiler compiles them as they
stand.

The generator writes **two** artifacts, `opcode.h` here and
`tools/isa/OPCODE_INVENTORY.md`; they and every table that indexes them belong
in one commit.

**The gate that runs here.**
`tests/cc3tab.sh` (`make check-cc3tab`, and part of `make check`) needs nothing
but python3 and holds `opcode.h`, the inventory, `n2/z8001/optab.c`'s two
tables, `n3/z8001/icode.c` and `tools/isa/optab.c` in lockstep — which is what
a half-landed regeneration breaks. Neither is optional reading if you touch
these files: the indices are **row numbers**, so a table one row out of step
makes cc2 encode a different instruction than cc1 asked for, silently.

**This directory is the only copy.** Both files are compiled into cc1/cc2/cc3
(`host/build-cc.sh` and `host/build-native.sh` add `-I src/cc/generated`), so
they live with the compiler source. The generator writes `opcode.h` straight
here.

## Files

- **`opcode.h`** — the MWC `Z*` opcode index: one `#define Z<MNEMONIC> <n>` per
  distinct decoder mnemonic, `NZOPCODE` at the end. Drop-in for
  `h/z8001/opcode.h`. The indices are arbitrary, but they are the row index of
  four separate tables and **must stay in lockstep with all of them**:
  `n2/z8001/optab.c`'s `opinfo[]` (the table cc2 links) and its `opname[]`,
  `n3/z8001/icode.c` (cc3's copy), and the draft `tools/isa/optab.c`.
  `make check-cc3tab` compares all four mechanically.
- **`OF_styles.h`** — the `OF_*` instruction-style codes, analogous to the i8086
  `cc2mch.h` styles; `h/z8001/cc2mch.h` includes it. Generated by
  `tools/isa/gen_optab.py`.

## Not here

The decoder **inventory** is a different table, and nothing compiles it: it
lives in `tools/isa/` (`OPCODE_INVENTORY.md`, `PST_CROSSCHECK.md`, `optab.c`),
with the two Python generators that read and check it. `tools/isa/README.md`
describes them, says how to read an inventory row, and lists the inventory's
known first-cut artifacts. `make check-isa` is the gate over that side.
